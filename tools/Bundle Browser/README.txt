This program allows you to add content to a Project Spark bundle

1. Close Project Spark and run BundleBrowser.exe

2. Open a bundle (see notes below)

3. Import content (Images, Sounds, Music, Kinect Emotes)


Optional
   - Remove selected
   - merged.assetdb is opened by default, a different Index can be picked

4. Build Bundle

5. Open Project Spark.

-----
More Detailed Information:

Open a Bundle

The 5 recommended bundles will be presented for selection, or you can select "Another Bundle" to open any bundle you want. 


Import 

Asks for a file, then converts the imported content to the correct format and adds it to the bundle. Content will appear in the gallery it belongs to.

Remove selected 

This deletes the highlighted thing from the bundle. You can reverse this action with Undo Removal until you build the bundle, and then it's permanent. Be sure to make a backup before using this, in case you accidentally delete something important.

Build Bundle 

The first time you use this program to build a bundle file it will create a backup folder in the same directory, and copy your current merged.assetdb and if sounds were added, your da45b9aed02e1e1b.bundle file to that folder. If you mess things up, copy those back to your \Project Spark\Assets\dlc folder to restore.

This button finalizes your changes, updates the .bundle files and merged.assetdb file and puts them in the Project Spark folder.
